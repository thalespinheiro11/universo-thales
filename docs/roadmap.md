# Roadmap

Este roadmap registra sequência, não compromisso de prazo.

## Fundação — atual

- documentação base e regras para agentes;
- rotas com locale explícito e fallback PT-BR;
- estrutura localizada para conteúdo institucional;
- identidade compartilhada entre traduções de projetos e artigos;
- configuração global e preparação de SEO localizado.

## Conteúdo

- revisar e consolidar textos institucionais PT-BR;
- traduzir conteúdo institucional e estudos de caso para inglês (concluído);
- traduzir os artigos do blog para inglês, com revisão do autor;
- migrar projetos prioritários para estudos de caso incrementais;
- definir disponibilidade e metadata de cada tradução de artigo;
- adicionar os currículos oficiais quando forem fornecidos.

## Experiência e SEO

- aprovar direção visual antes de qualquer redesign;
- implementar seletor de idioma acessível preservando contexto;
- aprofundar títulos, descrições e Open Graph específicos por página;
- revisar a indexação ao publicar cada nova tradução;
- validar sitemap após cada migração de conteúdo.

## Qualidade

- ampliar testes da resolução de locale e conteúdo;
- realizar auditoria direcionada de acessibilidade e performance;
- documentar o processo real de deploy quando ele for confirmado.
